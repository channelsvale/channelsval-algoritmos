Modulación PCM (Pulse Code Modulation)

Definición

La Modulación por Código de Pulsos o PCM (Pulse Code Modulation) es un método de conversión de una señal analógica a una señal digital. Consiste en muestrear la señal, cuantizarla y luego codificarla en una secuencia binaria. Es uno de los métodos más utilizados en telefonía, audio digital y telecomunicaciones.

Procedimiento para llevarla a cabo

  1. Muestreo: La señal analógica se toma a intervalos regulares para obtener muestras.
  2. Cuantificación: Cada muestra se aproxima a un nivel predeterminado.
  3. Codificación: Cada nivel cuantizado se convierte en un código binario.
  4. Transmisión: Los bits se envían a través del canal digital.

Aplicación

El PCM se utiliza en:

  • Telefonía digital
  • Sistemas VoIP
  • Audio en computadoras y estudios (WAV, AIFF)
  • Telecomunicaciones satelitales
  • Grabación y reproducción de sonido de alta calidad
